Cómo funciona el flujo

Cuatro pasos, con revisión antes de publicar
  1. 01 / Origen

    Primero, tus proyectos

    AutoPost revisa los commits recientes de los repositorios conectados. Si no hay novedades, puede tomar una idea de tu banco.

    GitHub tiene prioridad; el banco mantiene el flujo de temas activo.

  2. 02 / Borrador

    La IA prepara el texto

    Genera propuestas con el contexto de tu voz y el enfoque que selecciones. Puedes editar el texto antes de seguir.

    La propuesta es editable; no se publica por sí sola.

  3. 03 / Revisión

    Ajustas y apruebas

    Revisa el texto, adjunta imágenes y elige el perfil o página de LinkedIn que recibirá la publicación.

    Solo los posts que apruebes pasan a la cola.

  4. 04 / Publicación

    La cola se publica según la programación

    Configura la zona horaria y los horarios. Puedes revisar estados y resultados en el historial.

    El backend de AutoPost ejecuta los horarios y debe permanecer activo. GitHub Actions no participa en la publicación; para publicar con tu equipo apagado, despliega AutoPost en un servidor.

Redacción

Una estructura que puedes adaptar

Usa estas partes como guía. No hace falta incluirlas todas en cada publicación.

  1. Gancho

    Una observación concreta que invite a seguir leyendo.

  2. Contexto

    El problema, decisión o situación que viviste.

  3. Solución

    Qué cambiaste y por qué elegiste ese camino.

  4. Aprendizaje

    Una conclusión útil para alguien con un reto similar.

  5. Conversación

    Una pregunta sincera para abrir el intercambio.

Preguntas frecuentes

¿Puedo añadir imágenes a un post?+

Sí. Adjunta imágenes desde el editor y revisa la vista previa antes de aprobar.

¿Qué publicaciones llegan a LinkedIn?+

Las que apruebes y envíes a la cola, siempre que la cuenta esté conectada y el servicio de publicación esté activo.

¿Puedo elegir entre perfil y página?+

Sí. Conecta las cuentas que necesites y selecciona el destino antes de aprobar la publicación.

¿Cómo detengo las publicaciones automáticas?+

Usa la pausa de emergencia de AutoPost. Mientras el backend esté pausado o detenido, no se procesarán los horarios. Revisa el historial para confirmar el resultado de cada intento.
